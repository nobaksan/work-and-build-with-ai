# 발행 전 체크리스트
## 블로그
- [ ] SEO 메타 설명 작성됨
- [ ] 썸네일 이미지 설정됨
- [ ] 내부 링크 2개 이상 포함
- [ ] 외부 링크 출처 확인됨
- [ ] 카테고리/태그 설정됨
- [ ] 모바일 미리보기 확인
## LinkedIn
- [ ] 첫 줄 후킹 확인
- [ ] 해시태그 3-5개 포함
- [ ] 이미지 첨부 (선택)
- [ ] 멘션할 사람 태그
## Twitter
- [ ] 각 트윗 280자 이내
- [ ] 첫 트윗 후킹 강력함
- [ ] 마지막 트윗 CTA 포함
- [ ] 이미지/비디오 첨부 (권장)
## Instagram
- [ ] 캐러셀 이미지 10장 준비
- [ ] 캡션 작성 완료
- [ ] 해시태그 20-30개
- [ ] 첫 번째 댓글 해시태그 분리
