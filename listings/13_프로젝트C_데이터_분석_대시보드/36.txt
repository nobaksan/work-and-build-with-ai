시나리오 1: 월간 보고서 작성

상황: 매월 초 경영진에게 보고
Step 1: 데이터 준비
- ERP에서 지난달 데이터 엑셀로 추출
- 대시보드에 업로드
Step 2: 분석 실행
- '전체 분석' 버튼 클릭
- 필터로 지난달 기간 선택
Step 3: 인사이트 확인
- AI 인사이트 탭에서 핵심 발견 확인
- 필요시 Claude에게 추가 질문
Step 4: 리포트 생성
- 'PDF 리포트 생성' 클릭
- 필요한 차트만 선택
- 다운로드
Step 5: 보고서 보완
- Word에서 회사 양식에 맞게 편집
- 코멘트 추가

시나리오 2: 임원 질문 대응

상황: "왜 이번 달 매출이 떨어졌지?"
Step 1: 즉시 분석
- 대시보드에서 해당 기간 필터
- 전월 대비 비교 차트 확인
Step 2: 원인 파악
- 카테고리별 변화 확인
- 지역별 변화 확인
- 이상치 탐지 확인
Step 3: Claude에게 질문
"이번 달 매출이 15% 하락했어.
원인을 분석해줘. 가능한 원인을
가능성 순으로 나열해줘."
Step 4: 빠른 보고
- 1장 요약 PDF 생성
- 또는 스크린샷 + 코멘트

시나리오 3: 새로운 데이터 탐색

상황: 처음 보는 데이터셋 이해하기
Step 1: 데이터 업로드
- CSV/Excel 파일 업로드
- 자동 컬럼 인식 확인
Step 2: 기본 탐색
- 데이터 탭에서 미리보기
- 각 컬럼 타입과 분포 확인
Step 3: Claude에게 질문
"이 데이터에서 분석할 수 있는 것들이 뭐야?
어떤 인사이트를 얻을 수 있을지 알려줘."
Step 4: 분석 실행
- 추천 분석 순서대로 실행
- 흥미로운 발견 기록
Step 5: 심화 분석
"[흥미로운 패턴]에 대해 더 자세히 분석해줘"
