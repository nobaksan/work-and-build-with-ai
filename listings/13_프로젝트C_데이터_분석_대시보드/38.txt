확장 1: API 연동

Claude에게 요청:
"Google Analytics API 연동해서
실시간 방문자 데이터를 대시보드에 보여줘"
가능한 연동:
- Google Analytics (웹 트래픽)
- 쇼피파이/카페24 (이커머스)
- Salesforce (CRM)
- Google Sheets (간단한 DB)
- MySQL/PostgreSQL (DB 직접 연결)

확장 2: 예측 모델

Claude에게 요청:
"다음 달 매출을 예측하는 기능 추가해줘.
과거 12개월 데이터 기반으로."
예측 기능:
- 다음 달 매출 예측
- 계절성 반영
- 신뢰 구간 표시
- What-if 시뮬레이션

확장 3: 자동 알림
