Gmail API를 연동해서 이메일을 요약하는 스크립트를 만들어줘.

기능:
- 오늘 받은 이메일 목록
- 중요도 자동 분류 (긴급/중요/일반/스팸)
- 각 이메일 한 줄 요약 (Claude API 활용: API 키는 환경 변수 ANTHROPIC_API_KEY에서 읽고, 모델은 claude-haiku-5-5로 지정)
- 답장이 필요한 이메일 표시
- 발신자별 그룹화 옵션

개인정보 보호:
- 이메일 내용은 로컬에서만 처리
- 요약본만 저장
- 민감한 정보는 [REDACTED] 처리

분류 기준:
- 긴급: 제목에 "긴급", "URGENT", "ASAP" 포함
- 중요: 상사/클라이언트로부터, 질문 포함
- 일반: 그 외 업무 메일
- 참고: 뉴스레터, 알림
- 스팸: 광고, 프로모션
