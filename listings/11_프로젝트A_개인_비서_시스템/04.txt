# 프로젝트: 개인 비서 시스템

## 목표
매일 아침 5분 안에 하루를 파악할 수 있는 브리핑 시스템

## 핵심 기능
1. Google Calendar 일정 가져오기
2. Gmail 중요 이메일 요약
3. 할 일 목록 관리
4. 데일리 브리핑 생성

## 기술 스택
- Python 3.9+
- Google API (Calendar, Gmail)
- JSON 데이터 저장

## 일정
- Day 1: 폴더 구조 + 할 일 관리
- Day 2: 캘린더 연동
- Day 3: 이메일 요약 + 통합

## 성공 기준
- [ ] 터미널에서 한 번의 명령으로 브리핑 확인
- [ ] 모든 정보가 5분 내에 파악 가능
- [ ] 매일 자동 실행
