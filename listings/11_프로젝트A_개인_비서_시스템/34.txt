Windows 자동 실행 설정 (Task Scheduler)

[방법 1] GUI로 설정

1. Win + R → "taskschd.msc" 입력 → Enter
2. 오른쪽 "작업 만들기..." 클릭
3. 일반 탭:
   - 이름: "Daily Briefing"
   - "가장 높은 권한으로 실행" 체크
4. 트리거 탭 → "새로 만들기":
   - 시작: "매일"
   - 시작 시간: 오전 7:00:00
   - "사용" 체크
5. 동작 탭 → "새로 만들기":
   - 동작: "프로그램 시작"
   - 프로그램: python
   - 인수: "C:\Users\...\daily_briefing.py"
   - 시작 위치: "C:\Users\...\personal-assistant"
6. 조건 탭:
   - "컴퓨터가 AC 전원에 연결된 경우에만" 해제
7. "확인" 클릭

[방법 2] PowerShell 스크립트로 설정

$action = New-ScheduledTaskAction -Execute "python"
    -Argument "C:\Users\yourname\personal-assistant\scripts\daily_briefing.py"
    -WorkingDirectory "C:\Users\yourname\personal-assistant"

$trigger = New-ScheduledTaskTrigger -Daily -At 7:00AM

Register-ScheduledTask -Action $action -Trigger $trigger
    -TaskName "DailyBriefing" -Description "매일 아침 브리핑"

설정 완료!
