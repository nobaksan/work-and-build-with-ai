# 프로젝트명: 월간 보고서 자동화
## 1. 개요
- 목표: 매월 수동으로 하던 보고서 작성을 자동화
- 대상 사용자: 나 (업무 시간 절약)
- 핵심 기능:
- 엑셀 데이터 자동 수집
- 차트 자동 생성
- PDF 보고서 생성
- 이메일 자동 발송
## 2. 기술 스택
- 언어: Python 3.10+
- 라이브러리:
- pandas (데이터 처리)
- openpyxl (엑셀)
- matplotlib (차트)
- reportlab (PDF)
- smtplib (이메일)
## 3. 기능 명세
### 3.1 데이터 수집
- 설명: 지정된 폴더에서 엑셀 파일 읽기
- 입력: ./data/ 폴더의 xlsx 파일들
- 출력: 통합된 DataFrame
- 상태: ⏳ 대기
### 3.2 데이터 분석
- 설명: 월별 통계 계산
- 계산 항목: 총합, 평균, 증감률, 상위 5개
- 상태: ⏳ 대기
### 3.3 차트 생성
- 설명: 주요 지표 시각화
- 차트 종류: 막대, 선, 파이
- 상태: ⏳ 대기
### 3.4 PDF 생성
- 설명: 분석 결과를 PDF 보고서로
- 포함: 요약, 차트, 상세 데이터
- 상태: ⏳ 대기
### 3.5 이메일 발송
- 설명: 보고서를 관련자에게 발송
- 수신자: 설정 파일에서 읽음
- 상태: ⏳ 대기

## 4. 설정 파일 (config.yaml)

data_folder: ./data output_folder: ./output email: sender: my@email.com recipients:

boss@company.com

team@company.com

subject: "[월간보고서] {month}월 실적 리포트"

## 5. 실행 방법

전체 실행

python main.py

특정 월만

python main.py --month 2024-01

이메일 없이 (테스트)

python main.py --no-email
