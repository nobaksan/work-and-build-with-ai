# 프로젝트명: 고객 이탈 분석
## 1. 개요
- 목표: 고객 이탈 패턴을 분석하고 예측 모델 구축
- 배경: 최근 이탈률 증가, 원인 파악 필요
- 산출물:
- 분석 리포트 (인사이트)
- 이탈 예측 모델
- 대시보드
## 2. 데이터 소스
- 고객 정보: customers.csv (10,000건)
- 거래 내역: transactions.csv (500,000건)
- 서비스 이용: usage_logs.csv (1,000,000건)
- 고객 문의: support_tickets.csv (20,000건)
## 3. 분석 프레임워크
### 3.1 탐색적 데이터 분석 (EDA)
- [ ] 데이터 품질 확인 (결측치, 이상치)
- [ ] 기초 통계량 계산
- [ ] 이탈/유지 고객 분포 확인
- [ ] 변수간 상관관계 분석
### 3.2 피처 엔지니어링
- [ ] RFM 지표 계산 (Recency, Frequency, Monetary)
- [ ] 서비스 이용 패턴 지표
- [ ] 고객 문의 관련 지표
- [ ] 시계열 피처 (추세, 변화율)
### 3.3 모델링
- [ ] 베이스라인 모델 (로지스틱 회귀)
- [ ] 트리 기반 모델 (Random Forest, XGBoost)
- [ ] 모델 평가 및 비교
- [ ] 피처 중요도 분석
### 3.4 인사이트 도출
- [ ] 주요 이탈 요인 식별
- [ ] 고위험 고객 세그먼트 정의
- [ ] 개선 방안 제안
## 4. 기술 스택

- 시각화: Matplotlib, Seaborn, Plotly
- 모델링: Scikit-learn, XGBoost
