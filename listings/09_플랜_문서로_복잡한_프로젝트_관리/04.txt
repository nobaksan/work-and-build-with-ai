# 프로젝트명: 개인 포트폴리오 웹사이트
## 1. 개요
- 목표: 내 작업물과 경력을 보여주는 개인 웹사이트
- 대상 사용자: 채용 담당자, 클라이언트
- 핵심 기능:
- 자기소개 페이지
- 포트폴리오 갤러리
- 연락처 폼
- 블로그 (선택)
## 2. 기술 스택
- Frontend: HTML, CSS, JavaScript
- 호스팅: GitHub Pages (무료)
- 폼 처리: Formspree (무료 플랜)
## 3. 기능 명세
### 3.1 메인 페이지
- 설명: 첫인상을 주는 랜딩 페이지
- 포함 요소: 인사말, 핵심 역량, CTA 버튼
- 우선순위: 높음
- 상태: ⏳ 대기
### 3.2 포트폴리오 갤러리
- 설명: 작업물을 카드 형태로 표시
- 기능: 필터링, 모달 팝업
- 우선순위: 높음
- 상태: ⏳ 대기
### 3.3 연락처 폼
- 설명: 방문자가 메시지를 보낼 수 있는 폼
- 입력: 이름, 이메일, 메시지
- 유효성 검사: 필수
- 우선순위: 중간
- 상태: ⏳ 대기
## 4. 디자인 가이드
- 색상: #2563eb (파랑), #1f2937 (다크그레이)
- 폰트: Pretendard (한글), Inter (영문)
- 스타일: 미니멀, 클린
